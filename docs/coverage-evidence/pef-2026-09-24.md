# PEF sensor-payload coverage, 2026-09-24

## Strict Pentax Huffman variant

The real-file control is raw.pixls.us sample `Pentax - K10D - 12bit 12bit compressed (3:2).PEF`, SHA-256 `e35ae4154a468be3154f5f462e884ba5941f010d3e8f23d347fbec14809f44d3`. The repository API identified the file as CC0 on 2026-09-24. The downloaded file matched the repository's declared hash.

The sensor IFD declares compression `65535`, 12 bits per sample, width 3936, height 2624, strip offset 85472, and strip length 8126786. Pentax MakerNote tag `0x0220` supplies a 53-byte big-endian Huffman table at file offset `0x8b0`. The MakerNote begins at file offset 684, so rawz's bounded locator returns MakerNote-relative table offset 1540. At the recorded source revision, the unmodified stream reached rawz result `full` in ReleaseFast. The 2026-10-14 classification correction below supersedes that verdict without changing the historical measurement.

## PackBits variant

The historical Validate fixture `IMGP1754.PEF`, SHA-256 `86ec2383dbfda3eda38ca913b02874a70248efba6107aa304781c8d3779de8c9`, is a CC0 Pentax K100D file whose sensor IFD declares standard TIFF PackBits compression `32773`, 12 bits per sample, width 3040, height 2024, strip offset 73728, and strip length 9229440.

tiffz owns PackBits syntax and passes decoded bytes to rawz. rawz checks the packed-12 extent, then returns `structural` with reason `sample_values_have_no_integrity_signal`. Every 12-bit sample pattern is valid and this variant has no sensor checksum, so a parser cannot honestly promote it to full depth.

## Validate's independent measurement

Validate independently pinned rawz `ef74184` and exercised the same K10D file
for 1,000 rounds. It also deep-checked all three embedded JPEGs; sensor-only
validation left 1.35 MB of the file uncovered. With those previews included,
Validate measured 917/1000 overall, 99.0% shotgun detection, and 84.5% sniper
detection. The remaining single-bit sniper misses were 41 in embedded-JPEG
entropy data, 6 in metadata values, and 31 in the PEF strip.

The difference from rawz's 97/100 strip measurement is methodological. rawz
replaced one complete byte with a different value; Validate flipped one bit.
Either mutation can form another syntactically valid Huffman stream, and a
single-bit change does so more often here. Future family scorecards report both
models by name rather than comparing them as if they were the same trial.

## 2026-10-14 classification correction

Successful compression-`65535` syntax-to-end validation now returns
`structural(analytical_ceiling_unestablished)`. The validator still checks the
declared sample count, Huffman codes, predictor bounds, exact whole-byte end,
metadata bounds, and explicit work limit. The historical measurements above
remain evidence about those checks, but they do not establish an analytical
ceiling or a format-level residual class. Malformed streams retain their typed
failure codes and exact region-relative offsets.
